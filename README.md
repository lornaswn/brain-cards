# 🧠 脑宇宙 · 青春期大脑探秘卡（猫猫版）

一套以「青春期大脑发育」为主题的科普扑克牌：**17 张核心脑区卡**，主角是 **17 只表情各异的奶胖团子猫**——猫猫的情绪就是这片脑区正在做的事。这些猫共用一个名字：**「想开」（ThinkCat）**，兼作 App 名（思想的想、开放的开）。**实体样本、线上 App、家长小程序共用同一份设计源，效果完全一致。**

## 卡面结构

- **正面**：表情猫猫插画（大面积，铺在各脑区主题色舞台上，底部标注真实位置）→ 脑名（中文名 + 学名）→ 代号 → 一句话功能 → 功能详解
- **背面（家长手册）**：
  - 孩子可能会出现的症状
  - **✕ 家长容易这样误解**（红框）vs **✓ 正确看待**（品牌色框）——红/品牌色强对比，让家长一眼看清「错在哪、该怎样」
  - **底部二维码**：扫一扫跳家长小程序，免费看 1 条专属应对方案，更多需开通会员或单条购买（把原「可以这样做」放到了小程序里）

## 背面二维码与小程序流程（设计说明）

- **二维码唯一且可配置**：每张卡的二维码不同，深链到小程序里**那张脑区**的详情页（`?card=<id>`），扫哪张开哪张，比通用首页更顺手。**上线前必须把基地址换成你的真实域名**：
  ```bash
  # 在 src/build.mjs 顶部 QR_BASE 已改为读取环境变量，直接：
  QR_BASE="https://你的域名/parent-app/?card=" node src/build.mjs
  # 不传则使用占位域名 your-domain.example.com，打印前务必改掉
  ```
  二维码已放大到约占卡宽 1/4（≈15mm），扫码更轻松。
- **每个脑区 = 一个独立深链页**：小程序用 `?card=<id>`（扫码）或 `#c/<id>`（站内点击）打开对应脑区详情，内含「症状 + 错误看待(红) + 正确看待(品牌色) + 应对方案」。首页「🎁 免费看 1 条应对方案」按钮与扫码深链都指向这张页。
- **免费看 1 条 → 付费**：小程序里「错误 vs 正确看待」始终免费；「应对方案」为付费内容。**首次**解锁任一张免费（拉新钩子），之后需开通会员或单条购买。
- **支付为模拟**：当前为演示，`confirmPay()` 只写 `localStorage`，不产生真实扣费；真实上线时在此处接入微信/支付宝支付与会员系统即可。状态存于浏览器 `localStorage`。

## 互动玩牌（小程序内，家长孩子都能玩）

家长小程序顶部「玩牌」入口，内置三种轻量玩法，把一副牌变成亲子游戏：

1. **🎴 每日一抽**：随机抽一张脑卡 + 一句反思提示（"当孩子___时，是__在主导。今天你捕捉到了吗？"），可一键跳转该卡家长手册。
2. **🧠 翻牌配对**：翻开两张，把「脑名」和「代号」配成一对，记步数，练记忆也记知识点。
3. **🕵️ 情境断案**：给一段亲子情境，判断"哪个脑区在主导"，答完即出解析，8 题一轮。

## 源文件与再生成

```
src/cards.json      # 17 张卡全部文案（含 wrongView / parentView / coping / hook），改文案只动这里
src/catfaces.mjs    # 17 只表情猫的参数化生成器（node src/catfaces.mjs singles <dir> 可重出PNG）
src/render.js       # 卡面正反面渲染层（背面错误/正确对比 + 二维码位）
src/build.mjs       # 一键构建：node src/build.mjs → 重新生成 app + parent-app + print + 二维码
```

改完任何源文件后运行 `node src/build.mjs`，再按 README 说明用 chromium 出 PDF/预览图即可。
