## 重要：二维码域名
v1 卡背二维码当前指向 **占位域名 `https://your-domain.example.com/...`**（源码 `src/build.mjs` 第 40 行 `QR_BASE`）。
**印刷/推广前必须部署到真实域名，并通过环境变量重建：**
```
QR_BASE="https://你的真实域名/parent-app/?card=" node src/build.mjs
```
否则用户扫码打不开。

## 如何复现 v1
源码已随档保存在 `versions/v1/src/`：
```
cd versions/v1/src && node build.mjs
# 产物输出到 parent-app/index.html（与上层共用输出目录，重建前请先备份上层 parent-app）
```
