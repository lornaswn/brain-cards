# V2 全新版 · 快照说明

- **冻结时间**：2026-11-06（含四项体验改造后的版本）
- **结构**：`index.html` 为自包含产物（约 2.1MB，可离线打开）；`src/` 为当时源码（build.mjs + app.js + app.css + cards.json + quiz.json 等），可完整复现。

## 本版核心
- App 化外壳：底部 5 Tab（首页/脑区/断案/铲屎官/我的），移动端优先，最大宽 480px。
- 视觉基调：温暖+专业+可爱（珊瑚橙→柔紫渐变、奶油底、圆角卡片）。
- 内容沿用 V1 全部数据：17 脑区卡、150 题情景断案、铲屎官 17 卡心情映射 + 6 工具照顾 + 段位榜 + 付费。

## 本轮体验改造（2026-11-06）
1. **顶部返回按钮**：子页面（脑区详情/会员/加群/报告/测评）顶部显示「‹」，点击回父级/首页；Tab 页不显示。
2. **发育行为测评（新功能）**：25 题日常行为观察（参考 CBCL/Conners/SNAP-IV 频率量表思路，0 从不~3 总是），覆盖全部 17 脑区；答完生成「脑养成图」报告。入口：首页横幅、我的页、报告页。
3. **报告统一为「脑养成图」**：发育测评为主输入（直接观察孩子），情境断案为辅输入（家长练习）；含各脑区关注度分级（需多关注/可留意/较稳定）+ 给家长的一句话；含「不构成医学诊断」声明。
4. **铲屎官情绪区重排**：「情绪」与「孩子状况」同字号同级重（15.5px/15px）；应对事项**整列直接展示**，不再一条条点出；天数完成条件=2 件照顾任务。
5. **猫猫反应固定气泡**：点工具后反应气泡固定在屏幕底部（tabbar 上方），滚到任何位置都看得到；重渲染后自动补弹。
